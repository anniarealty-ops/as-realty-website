## Always Check Apple Education Store for Apple Products
Apple's Education Store offers real discounts (~$100 off) on all Macs, available to home users.
URL: https://www.apple.com/us-hed/shop → select "Home"
- Mac Mini M4 16GB/256GB = $499 (vs $599 regular) — confirmed March 2026
- Always check this FIRST before any third-party retailer

**Why:** Annia found this herself after I failed to mention it. It's the best Apple deal available without waiting for sales.

**How to apply:** Any time Annia asks about buying Apple products, check Education Store Home pricing FIRST. Always mention it.

## GO DIRECT TO STORES — NEVER USE ARTICLES FOR PRICES
When Annia asks for prices, deals, or product availability — go DIRECTLY to the store page using WebFetch. Never use web search articles or news for pricing. Articles lie, exaggerate, and show expired deals.

**Stores to fetch directly:**
- amazon.com — fetch the product page directly
- apple.com/shop — fetch directly
- bestbuy.com — fetch directly
- bhphotovideo.com — fetch directly
- walmart.com — fetch directly
- macofalltrades.com — fetch directly

**Why:** Articles showed $499 and $799 prices that were expired or wrong. Annia had to use another AI to find the correct link and real price. She should never have to do that.

**How to apply:** Use WebFetch on the actual store URL. If WebFetch fails (JavaScript block), tell Annia immediately — "I cannot read this store's live price, please paste the price you see." Never guess or cite articles.

## Cannot See Live Prices
Web search returns cached/article data — not live store prices.
Always tell Annia to verify the final price on the retailer's site before buying.

**Why:** Reported wrong Amazon prices multiple times because search results showed old sale prices.

**How to apply:** Always add "verify this price directly on [site]" when giving any product price.
