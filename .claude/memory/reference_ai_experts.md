## SOLOPRENEUR OPERATORS (how to run a serious business alone with AI)

13. **Arvid Kahl** — thebootstrappedfounder.com
    - Built Podscan (podcast database SaaS) solo using Claude Code exclusively for 6+ months
    - The 40-20-40 rule: 40% writing the prompt spec, 20% waiting, 40% reviewing every line
    - Voice-to-code: speaks prompts with Whisper Flow instead of typing → faster spec creation
    - Contextual anchoring: open 2-3 core files BEFORE running agent → don't overwhelm with full codebase
    - Key insight: treat AI as a knowledgeable colleague, not an employee — always review, never verbatim
    - For Annia: applies to building expired sniper, class action agent, and any automation

14. **Matthew Gallagher** — Medvi founder (not a blogger — a blueprint)
    - Built $1.8B telehealth company with $20K, 2 employees, AI stack costing $3-12K/year
    - The Gallagher Model: treat every business function as an external API, not a hire
    - AI stack: Claude + ChatGPT (code/copy) | Midjourney + Runway (visuals) | ElevenLabs (voice/CS)
    - Key move: outsourced regulated functions (doctors, pharmacy, legal, accounting) to licensed services
    - Every hire must justify itself against AI alternative — headcount discipline
    - Failure lesson: production break → hired 2 CONTRACT engineers (not full-time) → right-sized response
    - For Annia: the real estate equivalent is fully mapped in /gallagher-model skill

## QUALITY & PRODUCTION ENGINEERING

15. **Shreya Shankar** — shreyashankar.com | co-teaches AI Evals with Hamel
    - Best on: prompt drift (your prompts silently degrade over time), data quality in production
    - Key warning: small iterative prompt changes accumulate into failure without tracking
    - Rule for Annia: any agent running on autopilot (expired sniper, class action) needs monthly output review
    - Partition monitoring: check outputs by category (by ZIP code, by lead type) not just overall

16. **Eugene Yan** — eugeneyan.com | ex-Amazon applied ML
    - Best on: what actually breaks AI systems in production (not demos)
    - The 7 patterns: Evals → RAG → Fine-tuning → Caching → Guardrails → Defensive UX → Feedback loops
    - Critical rule: "The model isn't your product — the system around it is." Design for model swappability.
    - LLM economics rule: even cheap LLMs aren't cheap at consumer scale — batch and cache aggressively
    - For Annia: build feedback into every agent from day 1 (log what worked, what was ignored)
