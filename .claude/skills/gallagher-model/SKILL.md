---

## THE GALLAGHER PRINCIPLE (understand this first)

He didn't build a company. He built a **system of APIs.**

Every business function = an external service you plug into, not a person you hire.
- Doctors → CareValidate (API)
- Pharmacy → OpenLoop Health (API)
- Legal → LegalZoom → external firm (API)
- Code → Claude/ChatGPT (API)
- Marketing → Midjourney + Runway (API)
- Customer service → ElevenLabs custom agent (API)
- Accounting → AI first, then external firm (API)

**He held exactly two things in-house:** digital marketing + user experience.

Everything else: outsourced to licensed services, AI tools, or contractors on demand.

## THE 5-LAYER GALLAGHER STACK (apply to any function)

### Layer 1 — AUTOMATE FIRST
Can Claude, an agent, or a $20/mo tool do this without you?
- Lead qualification text → YES → SimpleTexting autoresponder
- Listing description → YES → /listing-description skill
- Follow-up sequence → YES → /follow-up-sequence skill
- CDA generation → YES → /cda-generator skill

### Layer 2 — OUTSOURCE SECOND
If AI can't do it, can a licensed service or contractor?
- Transaction coordination → TC ($350/deal, saves 15 hrs)
- Photography → photographer ($150-250/listing)
- Showing coverage → referral agent (split the showing fee)
- Legal questions → RE attorney (pay per question)

### Layer 3 — TEMPLATE EVERYTHING
Any task you do more than once → build a template for it.
- Every seller script → /expired-listing-script
- Every buyer email → /client-outreach
- Every social post → /post
- Every listing appointment → /listing-presentation

### Layer 4 — FEEDBACK LOOP
Every AI output that gets used (or ignored) → log it.
- Which SMS got responses? Which got unsubscribes?
- Which listing descriptions got showings?
- Which content got DMs?
Use `/diagnose` monthly on your highest-volume outputs.

### Layer 5 — HOLD THE TWO THINGS
Like Gallagher held marketing + UX, Annia holds:
1. **Relationships** — the listing appointment, the negotiation, the trust conversation
2. **Lead strategy** — which market, which list, which message, which offer

Never outsource or automate these two. Everything else is fair game.

## GALLAGHER'S CRITICAL LESSONS FOR ANNIA

**On headcount:**
His previous company had 60 employees and never profited. Medvi has 2 and prints money.
→ Annia's rule: every potential hire gets evaluated against: can Claude + a TC + a contractor do this for less than $500/month?

**On failure response:**
When his site broke and he lost 200 customers, he hired 2 contract engineers — not a full-time SRE team.
→ Annia's rule: when something breaks, fix it surgically. Don't build an empire around one failure.

**On what AI can't do:**
He eventually moved legal and accounting to humans because AI generated wrong information in sensitive areas.
→ Annia's rule: AI writes the first draft of everything. Annia reviews anything with a number, a legal term, or a client's name in it.

**On loneliness:**
He considered hiring just to have company.
→ Annia's rule: Vivir Bonito community + mastermind or REIA group = the human layer. Keep it.
