When Annia provides an expired listing lead, generate:

1. **Initial SMS** — under 160 chars, no pressure, curiosity-based
2. **Day 3 Follow-up SMS** — softer, mention bilingual service
3. **Day 7 Final SMS** — last touch, leave door open
4. **Phone Script** — 60-second opener with 2 objection handlers
5. **Voicemail Script** — 20 seconds max, end with callback number

Tone: confident, empathetic, never desperate. Annia is the expert, not chasing.
Always include: (407) 492-1114 and dot.cards/annia
Mention: "Hablo español" when name sounds Hispanic.
End every script sequence with a recommended follow-up timing.
