## AI Working Patterns (Always Apply)
- **95% Confidence Rule:** Before building ANYTHING, ask clarifying questions one at a time until confident. Never start building based on assumptions.
- **Plan Mode First:** Use Shift+Tab to activate Plan Mode. Present full plan before touching any file. 90% planning, 10% building.
- **/compact:** When conversation gets long or slow, run /compact to compress history and keep working fast.
- **Reset when stuck:** If results are bad after 2 tries, start a fresh conversation — don't keep patching.
- **Ask for volume:** When brainstorming (listing ideas, client scripts, content topics) always generate 20-50 options, not 5. AI doesn't get tired.
- **Use branching:** Edit a previous message instead of re-asking from scratch when you want a different angle on something.
- **Frame translation:** One piece of content → multiple audiences. Example: one listing → seller letter + IG caption + SMS + email. Use /frame for this.
- **Perspective testing:** Before sending any important message, ask Claude: "How would a skeptical [buyer/seller/title officer/investor] react to this?" Use /perspective for this.
- **Model selection (Karpathy rule):** Sonnet for daily tasks. Opus (/model) for hard analysis — complex deals, agent building, legal docs, strategic decisions.
- **Code post-scarcity (Karpathy):** Generated code is disposable. Delete freely. Rebuild without guilt. Don't be precious about it.
- **DO NOT use AI when actively learning something new** (Mollick rule) — if you're studying contracts, Florida law, or negotiation, work through it yourself. AI robs you of the struggle that creates expertise.
- **DO use AI as a co-founder** for unfamiliar domains — accounting questions, tech questions, legal research, marketing copy you've never written before.

## When to Use AI vs. Not (Mollick's Framework — Applied to RE)
**USE AI for:**
- Generating 50 listing headline options and picking the best one
- Writing the same property description for 4 different audiences (seller, buyer, investor, social)
- Getting hostile buyer reactions to your listing price before it goes live
- Drafting scripts, emails, SMS — anything where volume = quality
- Research on neighborhoods, comps, permit history, school ratings
- Summarizing long contracts (but verify key numbers yourself)
- Coding agents, automations, website updates

**DO NOT use AI for:**
- Learning Florida real estate law — read it yourself
- Writing offers where a small error matters — review every number personally
- Anything where you're the expert and AI would skip your best judgment
